# 校园测试平台学生字段说明

本说明定义课程原型使用的虚构学生样本，不提供真实学校身份认证服务。学生可在本地用固定样本模拟平台返回值，无需接入外部账户系统。

字段版本：2026-10-01，v1.0；发布方：教学测试平台维护组；适用于 2026 年开放日课程原型。

## 字段定义

| 字段 | 类型与要求 | 含义 |
| --- | --- | --- |
| student_id | 非空字符串，不能只有空白 | 样本中的稳定学生标识，同一学生修改姓名时该值保持不变 |
| name | 非空字符串 | 显示姓名，不保证唯一 |

不提供手机号作为学生身份。报名接口应校验使用的标识和输入，不将缺失值、null、空字符串或纯空白视为有效学生。

## 样本

```json
[
  {"student_id": "S20260001", "name": "林同学"},
  {"student_id": "S20260002", "name": "林同学"},
  {"student_id": "S20260003", "name": "陈同学"}
]
```

测试“同一学生修改姓名”时，保持 student_id 为 S20260001，将显示姓名改为林同学修改版。并发容量测试可生成不同、有效且符合以上含义的虚构标识。

相同的初始数据也提供为[虚构学生样本 JSON](虚构学生样本.json)。容量测试生成的标识应与预置报名和其他场景分开，避免把重复请求误当作容量测试。

## 原型边界

本作业验证指定身份标识下的报名规则。固定样本不等于真实认证，课程原型不保证阻止伪造身份；成果说明需要保留这个范围。
